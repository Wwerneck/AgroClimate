AgroClimate Data Platform

Plataforma de Engenharia de Dados para ingerir clima da Open-Meteo, organizar um Data Lake Bronze/Silver/Gold, processar com PySpark, validar qualidade e carregar um Data Warehouse PostgreSQL.

Ingestao

Cliente Open-Meteo com timeout, retry, logs, metadados e carga incremental.

Data Lake

Camadas Bronze, Silver, Gold e Quarantine usando Parquet e particionamento.

Warehouse

Modelo estrela com dim_date, dim_location, dim_source e fact_weather_daily.

Orquestracao

DAG Airflow com etapas explicitas para ingestao, qualidade, Spark e PostgreSQL.

Pipeline

Open-Meteo APIDados horarios meteorologicos para cidades estrategicas do agro brasileiro.
BronzeDados quase crus com ingestion_timestamp, source e pipeline_execution_id.
SilverTipos padronizados, hash deterministico, deduplicacao e validacoes.
GoldMetricas diarias, acumulados, amplitude termica e riscos exploratorios.
PostgreSQLCarga idempotente com INSERT ... ON CONFLICT no modelo dimensional.
DashboardStreamlit preparado para consumir o warehouse, sem consultar a API diretamente.

Como executar

cp .env.example .env
docker compose up -d
pytest
python -m src.pipeline
